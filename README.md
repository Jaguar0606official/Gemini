# Gemini Network Assistant — MVP 0.1

Начальный WPF-проект для Windows 10/11.

## Что уже реализовано
- WPF-интерфейс на .NET 8.
- Проверка DNS для контрольных доменов Google.
- Проверка TCP-подключения к порту 443.
- HTTPS GET-проверка корневых адресов.
- Отображение результатов в окне приложения.

## Чего пока нет
- Автоматического переключения DNS.
- Обхода региональных ограничений Google.
- Интеграции с Ollama.
- Автозапуска и фонового мониторинга.

Эти функции добавляются отдельными этапами после проверки основы.

## Запуск
1. Установить Visual Studio 2022 с workload **.NET desktop development** и .NET 8 SDK.
2. Открыть `GeminiNetworkAssistant.csproj`.
3. Собрать и запустить проект (F5).

Проект предназначен для Windows. Диагностика не меняет системные настройки.
